# zk-age

zk-age is a backend service that lets web2 applications verify age predicates (18+, 21+) using Groth16 zero-knowledge proofs settled on the zkVerify network — no personal data touches your server.

## When to use

Adding compliant age-gating to a web2 app without collecting identity documents.

## Install

```
cargo install zk-age
```
